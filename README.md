# ZERO SEARCH - Tafuta maarifa. Chunguza ulimwengu.

Zero Search ni injini ya utafutaji nyepesi, ya haraka na rafiki kwa mtumiaji wa Tanzania. Imetengenezwa ili kumsaidia kila mtu kupata taarifa haraka bila matangazo mengi.

Live Demo: https://zerogravityapp.unaux.com/?i=1

FEATURES:
- Fast Search - Tafuta chochote au andika web address
- Voice Search - Tafuta kwa sauti
- Image Search - Tafuta kwa picha
- Light & Fast - Inafanya kazi haraka hata kwenye mtandao mdogo
- Quick Links - YouTube, Music, Facebook, Play Game, News
- Mobile First - Imetengenezwa kwa simu
- Minimalist Design - ZERO bloat
